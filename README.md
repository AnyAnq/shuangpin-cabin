# 双拼小筑 Shuangpin Cabin

双拼小筑是一个支持小鹤双拼和自然码的中文打字练习网站。可以跟着逐字编码熟悉键位，也可以用自己的中文输入法练习长文跟打，完成后查看速度、准确率和错句。

[在线练习](https://iqueue.dpdns.org) · [备用地址](https://shuangpin-cabin.pages.dev/)

## 开始练习

1. 选择小鹤双拼或自然码，再选择练习内容。
2. 将输入法切到英文状态，直接按键输入汉字对应的双拼编码。页面下方的键盘可用来查看键位。
3. 输入时会显示进度、准确率、用时和连击数。按 Backspace 可以退回修改，完成后可继续下一组。

刚开始学双拼，可以从侧栏的「新手课程」进入。课程分为声母起步、韵母定位、易混组合、词句连打四个阶段，每课都输入完整双拼编码，准确率达到 95% 即为达标。两种方案分别记录课程成绩，也可以直接选择想练的阶段。

熟悉键位后，可以在设置中关闭逐字编码提示。

## 提速练习

侧栏的「提速练习」使用中文输入法直接跟打。简码、辅助码和选词由你使用的输入法处理，页面只比较上屏后的文字，不要求每字输入两个按键。

可选三篇内置的现代文，也可以粘贴自己的原文，每篇最多 2,000 个字符。跟打区需要直接输入，不能粘贴或拖入答案。输入中的错字只作标记，不会打断输入；可以继续打，也可以用鼠标、方向键和退格自行修改。最后点击「完成并评测」，即使漏字或多字，也不会提前结束。

计时从第一次输入或开始组词时开始，中途停顿也计入用时。报告按最终文本对齐统计错字、漏字和多字：

- 有效字速：正确字符数 ÷ 用时（分钟）。
- 准确率：正确字符数 ÷（原文字符数＋多字数）。
- 标点、数字、英文大小写和正文内部空格都参与判定；排版换行及每行首尾空白忽略。

报告保留最多三段错句，也会收集输入中出错、后来改好的句子。可以复练这些句子、重练全文，或换一篇。同文全文练习会显示与上次成绩的差异；错句复练单独记录，不混入全文速度趋势。保存失败时报告仍留在页面，可以重试。

## 练习内容

| 模式 | 内容 |
| --- | --- |
| 诗词句子 | 在线获取诗词，标题和作者单独展示，只练习正文汉字 |
| 绕口令 | 用绕口令练习连续输入 |
| 词库练习 | 选择一个已安装词库，或用「混合」练习多个词库 |
| 易错练习 | 根据之前的错误，按声母、韵母等错因分组复练 |

诗词和绕口令可以点击「换一组」更新。获取失败时会显示提示，并保留当前内容和输入进度，稍后重试即可。

在「词库」页可以安装、更新在线词库，也可以管理自己导入的本地词库。所有练习功能和在线词库均免费使用。

## 记录与每日目标

记录页分为「键位练习」和「中文跟打」。前者展示当前双拼方案最近 7 天的练习组数、时长、平均准确率和输入速度（WPM），以及需要优先复练的错误；后者展示全文跟打趋势，并可打开每次的完整报告。

每日目标默认是 10 分钟，可以在记录页调整。两种方案的键位练习、中文跟打和错句复练，共同计入已完成的练习时长；每组从首次输入开始计时，中途停顿也会计入用时。

## 自定义词库

在「设置 → 词库与项目 → 导入本地词库」中选择文件，检查词条预览，按需修改名称、作者等信息，再点击「确认导入」。回到「词库练习」后，就能选择它开始练习。

支持 TXT、CSV 和 JSON。词条须为纯中文，每条最多 12 个汉字；含英文、数字或标点的词条会被过滤。

### TXT：一行一个词

保存为 UTF-8 编码的 `my-words.txt`：

```text
字符串
初始化
数组
客户端
```

### CSV：附带权重和标签

```csv
text,weight,tags
字符串,100,编程/基础
初始化,99,编程
数组,98,数据结构
```

第二列是可选权重，第三列是可选标签；标签可用 `/`、空格或 `、` 分隔。权重越高，词条在生成练习组时排序越靠前。

TXT 和 CSV 会跳过空行及以 `#`、`//` 开头的注释行。重复词条会合并，保留较高权重。

### JSON：保存完整词库信息

JSON 须为词库对象，不能只写词条数组。下面是一个可导入的示例：

```json
{
  "schemaVersion": 1,
  "id": "my-tech-vocabulary",
  "name": "技术术语",
  "version": "1.0.0",
  "author": "你的名字",
  "entries": [
    { "text": "字符串", "weight": 100 },
    { "text": "初始化", "weight": 99 },
    { "text": "数组", "weight": 98 }
  ]
}
```

示例中的顶层字段均为必填，`schemaVersion` 当前固定为 `1`。还可填写 `license`、`description` 和 `tags`；每条词条至少包含 `text`，也支持 `weight`、`tags` 和 `source`。

再次导入相同 `id` 的 JSON 词库会替换该 ID 对应的已有词库。本地词库可在「词库」页导出为 JSON，方便备份或换浏览器时重新导入。

## 数据保存在哪里

练习记录、跟打报告、错题、设置和已安装词库保存在当前浏览器的 IndexedDB 中，不提供账号同步。跟打报告包含本次原文和交卷文本，本地导入的词库文件和练习输入记录不会上传。

清理网站数据或更换浏览器后，这些本地数据不会保留。设置中的「清空练习记录」会清除键位记录、跟打报告和由记录计算的课程进度，保留每日目标设置；「清空键位错题」只清除键位错题，不影响跟打报告中的错句。

诗词、绕口令和每日一言需要联网获取，安装或更新在线词库也需要网络。页面已加载后，内置课程、已安装词库和中文跟打可以断网练习。

## 本地开发

建议使用 Node.js 24 LTS 和 npm。在项目目录运行：

```bash
npm ci
npm run dev
```

打开终端显示的地址。默认端口为 5173，被占用时 Vite 会选择下一个可用端口。浏览器数据按访问地址分别保存，`localhost` 和 `127.0.0.1` 不共用记录。

开发服务已经配置内容接口和在线词库代理，无需先部署网站，也无需为公共词库配置 token。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务 |
| `npm test` | 运行单元与组件测试 |
| `npm run test:watch` | 监听文件变化并运行测试 |
| `npm run e2e` | 运行浏览器测试 |
| `npm run build` | TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 预览构建产物 |

浏览器测试使用 Playwright，当前配置要求安装 Microsoft Edge，并会自动启动本地开发服务。

### 代码结构

前端使用 Vue 3、TypeScript 和 Vite，Pinia 管理状态，Dexie 负责本地存储。拼音由 pinyin-pro 生成，再按双拼方案映射为编码。

```text
src/
  components/   练习区、键盘、设置等界面组件
  views/        练习、课程、记录和词库页面
  domain/       双拼编码、练习判定、错题与词库规则
  stores/       页面状态与练习流程
  services/     在线内容和词库请求
  storage/      IndexedDB 数据读写
functions/      Cloudflare Pages 接口代理
vocabulary/     词库文件与配置说明
tests/          单元与组件测试
e2e/            浏览器测试
```

### 部署与内容接口

当前网站部署在 Cloudflare Pages，构建命令为 `npm run build`，输出目录为 `dist`。`functions/` 提供诗词、绕口令、一言和词库的同域代理；部署时需要一并保留。若使用其他托管平台，需配置对应的代理接口。

在线词库的目录、索引和更新方式见[词库配置说明](vocabulary/README.md)。
